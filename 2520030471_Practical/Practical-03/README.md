System Calls Used
fork() – Creates a new child process.
getpid() – Shows the ID of the current process.
getppid() – Shows the ID of the parent process.
Process States

A process can have different states:

1. Ready
The process is ready to run but waiting for the CPU.

2. Running
The process is running on the CPU.

3. Waiting
The process is waiting for something to finish.

4. Terminated
The process has finished and stopped.

Tools Used for Monitoring
ps – Shows the running processes.
top – Shows processes and their CPU and memory usage.
/proc – Shows information about processes.
Observation

We can use ps, top, and /proc to check processes.
